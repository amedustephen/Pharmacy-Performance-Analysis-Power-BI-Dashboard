# Scripts

   Place reusable Python (.py), R (.R), or shell (.sh) scripts here.

   Scripts are meant to be run repeatedly or reused across projects. 

   Examples:

   Production-grade Python packages, split into subdirectories like data_pipeline/, features/, models/, and utils/.

   Modular production code containing separate packages for extract/, transform/, and load/ logic.

   Active Power BI project files saved in the modern text-based format.
   *.pbip — The main Power BI project metadata file.
   *.Dataset/ — Contains data model definitions, tables, and DAX measures (model.bim).
   *.Report/ — Contains the visual layout, theme configs, and sheet definitions (report.json).

   Helper JavaScript or Python files used in n8n Code nodes
